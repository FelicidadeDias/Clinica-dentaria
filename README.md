# Clínica Dentária Biclinic — Website demonstrativo

Landing page responsiva criada como proposta comercial pela **Fely e Amigos | Soluções Digitais**.

## Publicação
Repositório: https://github.com/FelicidadeDias/Clinica-dentaria

Para publicar pelo GitHub Pages:
1. Abra **Settings → Pages**.
2. Em **Build and deployment**, seleccione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)**.
4. Clique **Save**.

URL esperado: https://felicidadedias.github.io/Clinica-dentaria/

## Observações
Este website é uma demonstração não oficial. Contactos, serviços e localizações foram reunidos a partir de fontes públicas. Confirmar com a clínica antes de usar em produção. Não foram incluídos preços, testemunhos inventados ou alegações médicas.
